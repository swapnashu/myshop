Sales & Expenses

Cash & online entries with remarks. Tap any entry to edit; today / week / month / all views with search.

Customer Khata

Give goods on credit, record payments, see each customer's running balance — and share the ledger on WhatsApp.

Supplier Ledgers

Material received and payments made per supplier, editable entries, auto-calculated balance.

Cash Book & Day Close

Opening cash, cash sales, khata collections, expenses and supplier payments — close the day and keep history.

Reports & Charts

Daily / weekly / monthly net position, 30-day trend bars, expense split pie and per-day sales table.

Edit History (Admin)

Every edit and delete is logged with old → new values, time, shop and user — open the History tab to review it.

Offline Mode

Add sales, expenses and ledger entries without internet — the app queues them and auto-syncs when you're back online.

Export & Backup

Download CSV for Excel or a full JSON backup straight from Settings.

Secure by Design

Fingerprint unlock, show/hide passwords, rotating session tokens, rate-limited login, server-side guards. Multi-shop roles included.

Getting started

  1. Download & install the APK (allow install unknown apps once).
  2. Log in with the admin account (mobile + password).
  3. In the app: Shops tab → add shop; Members tab → create each employee's login and assign a shop.
  4. Employees install the same APK and log in with the credentials you created — fingerprint unlock gets offered automatically.
